# Интерактивное приглашение

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для тестирования можно использовать VS Code и расширение Live Server.

## Что настроить перед публикацией
В `index.html` найдите блок финального экрана и замените:
- `Hotel Paradise` на реальное название места;
- `ул. Примерная, 12` на адрес;
- `Комната 306` на номер/дополнительную информацию.

Фото загружаются с Unsplash, шрифты — с Google Fonts, поэтому для их загрузки нужен интернет. Чтобы сайт работал полностью автономно, скачайте изображения и шрифты локально и замените URL в `style.css`.

Сайт сделан на чистых HTML, CSS и JavaScript, без сборки и библиотек. Адаптивен для телефона и компьютера. Кнопка «Нет» убегает от курсора и при попытке нажатия на сенсорном экране.
